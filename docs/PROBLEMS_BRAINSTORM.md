## Step 2: Quick Prioritization Questions

For each problem, ask yourself:

### ✅ Must Include (High Priority)
- [ ] Is it recent (last 2 years)?
- [ ] Did it have measurable impact?
- [ ] Is it relevant to the job I'm applying for?
- [ ] Was it technically challenging?
- [ ] Can I explain it clearly in 2-3 sentences?

**If 4+ yes → Include in resume**

### ⚠️ Maybe Include (Medium Priority)
- [ ] Is it a common problem many developers face?
- [ ] Did it improve team productivity?
- [ ] Is it still relevant to current tech stack?

**If 2-3 yes → Keep as backup for interviews**

### ❌ Skip (Lower Priority)
- [ ] Is it too old (3+ years)?
- [ ] Was it a minor fix?
- [ ] Is it not relevant to frontend development?

**If 2+ yes → Skip or mention briefly**

## Example Format for Resume

### Key Problems Solved

**Problem 1: Editor Performance & File Upload Bottleneck**
- **Problem:** Blocknote editor lagged with multiple files and content saving was slow due to file uploads blocking the main thread, with base64 data making JSON content extremely large and insecure.
- **Solution:** Implemented Service Worker architecture to offload file uploads, using direct S3 uploads with pre-signed URLs and storing only file references in JSON.
- **Impact:** Eliminated editor lag, reduced content saving time, improved application performance, and reduced server load.

## Quick Checklist Before Adding to Resume

For each problem, ensure you can answer:

- [ ] **What was broken?** (Clear problem statement)
- [ ] **What did I do?** (Clear solution)
- [ ] **What changed?** (Clear impact/outcome)
- [ ] **Is it relevant?** (Matches job requirements)
- [ ] **Can I explain it?** (Clear in 30 seconds)

---

## Recommended: Top 3-5 Problems for Resume

Based on typical resume length, include:
- **3-5 problems** in a dedicated section
- Each problem: 2-3 sentences (Problem → Solution → Impact)
- Focus on **recent, impactful, and relevant** problems
