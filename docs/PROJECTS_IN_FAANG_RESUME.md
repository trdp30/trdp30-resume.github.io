# Should Projects Be Included in FAANG Resumes?

## Quick Answer

**For FAANG resumes: Generally NO, unless they're exceptional.**

## Detailed Analysis

### When to INCLUDE Projects

#### ✅ Include If:
1. **Open Source Contributions**
   - Significant GitHub stars (1000+)
   - Active contributors
   - Used by other companies/projects
   - Example: "Maintained React library with 5K+ stars, used by 200+ companies"

2. **Personal Projects with Real Impact**
   - Measurable users (10K+)
   - Revenue generated
   - Real-world adoption
   - Example: "Built SaaS tool with 50K+ users, generating $100K ARR"

3. **Skills Not in Work Experience**
   - Technologies you want to showcase
   - Different domain expertise
   - Example: "Built ML-powered app using TensorFlow.js" (if not used at work)

4. **Exceptional Technical Complexity**
   - Novel solutions to hard problems
   - Published research/technical blog posts
   - Conference talks or technical writing

#### ❌ Exclude If:
1. **Work Projects** (Your Current Situation)
   - These belong in **Work Experience**, not a separate section
   - Already covered in your job description
   - Redundant and wastes space

2. **Simple/Tutorial Projects**
   - Todo apps, calculators, basic CRUD
   - No real complexity or impact
   - Makes you look junior

3. **No Clear Impact**
   - Can't quantify results
   - No users, no adoption, no metrics
   - Just "built X using Y"

4. **Space Constraints**
   - FAANG resumes should be 1-2 pages
   - Every line must add value
   - Work experience is more important

## FAANG Resume Best Practices for Projects

### If You DO Include Projects:

#### Format:
```
Open Source / Personal Projects (Optional Section)

[Project Name] | [Technologies] | [GitHub/URL]
• [Impact-focused bullet with metrics]
• [Technical complexity/innovation]
• [Adoption/usage metrics]
```

#### Example Good Project Entry:
```
React Performance Profiler | React, TypeScript, Webpack | github.com/user/profiler
• Built open-source performance profiling tool with 2K+ GitHub stars, 
  used by 50+ companies to identify React performance bottlenecks
• Implemented custom Webpack plugin reducing bundle analysis time by 80%
• Featured in React Newsletter and adopted by 3 FAANG companies
```

### If You DON'T Include Projects (Recommended):

Focus on:
1. **Stronger Work Experience** bullets with more detail
2. **Key Achievements** section highlighting top metrics
3. **Technical Skills** section (already have this)
4. **More space** for quantified impact in work experience
